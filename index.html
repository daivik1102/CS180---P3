00 / THE IDEA

Learn a direction.
Follow it to the image.

Flow matching trains a neural network to predict how an image should change at a given point along a path from Gaussian noise to a real image. At inference time, Euler integration repeatedly asks for that direction and takes a small step.

Optimal transport path and target velocityxt = (1 − t)x0 + tx1    ·    u(xt,t) = x1 − x0
01 — TRAIN

Pick endpoints

02 — PREDICT

Estimate velocity

Train the UNet to predict the constant direction from noise toward the data image.

03 — SAMPLE

Integrate the field

Start from noise and repeatedly update the image with the learned velocity.

03 / NOTES

Implementation
choices.

The code is organized around reusable model and sampling functions. All generated files are saved separately from source so experiments can be rerun without editing the report.

Reproducibility
Both Colab runs used the notebook's fixed seed. The exported galleries include image edits, sampling results, training curves, and epoch-by-epoch comparisons.
Runtime
Part B requires PyTorch and torchvision. The PixNerd checkpoint/runtime is supplied by the course notebook and is not bundled with this repository.
